# GitHub Agent Skill

**Domain:** Software Engineering / Agentic AI
**Status:** Active

## Overview
The GitHub Agent allows AI models to search for and retrieve relevant repositories and code snippets from GitHub. This is critical for auto-updating agents that need to discover new skills or libraries.

## Capabilities
- `search_repositories(query, limit)`: Searches GitHub and returns top repositories matching the query.

## Implementation
- **Language:** Python
- **Dependencies:** Standard library (`urllib`, `json`)
- **Main Class:** `GitHubAgent`
